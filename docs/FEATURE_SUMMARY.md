## :zap: 最新優化

### :clock10: 精準時間調度系統 :new:
- **全域任務追蹤**: 使用 `rate_check_task` 和 `health_check_task` 變數追蹤任務狀態
- **優雅取消**: 使用 `CancelledError` 處理任務取消，避免異常日誌
- **任務重新調度**: 每日維護時重新啟動所有定期任務，防止24小時運行的時間漂移
- **狀態監控**: `/status` 指令顯示監控任務的實際運行狀態

### :fire: API 調用優化
- **優化前**: 每個伺服器單獨調用 API (N次調用)
- **優化後**: 全域統一調用一次，然後分發給所有伺服器 (1次調用)
- **效能提升**: 以2個伺服器為例，減少50% API請求

### :floppy_disk: 健康檢查數據持久化
- **自動保存**: 每次健康檢查結果自動寫入 server_data.json
- **歷史追蹤**: 保留檢查時間、結果和詳細狀態信息
- **長期分析**: 支援系統健康趨勢分析
- **圖表生成**: 1-30天匯率趨勢圖表
- **歷史記錄**: 30天匯率歷史數據保存
- **數據可視化**: 專業PNG圖表，包含閾值線

#### :floppy_disk: 數據管理功能
- **自動備份**: 每日備份，智能清理策略
- **數據持久化**: JSON格式，支援手動備份
- **健康檢查記錄**: 自動保存系統健康狀態 :new:

#### :hospital: 健康監控系統 :new:
- **全面健康檢查**: API、資源、數據完整性、文件系統
- **快速健康檢查**: 輕量級檢查，適合頻繁執行
- **健康歷史追蹤**: 保留檢查記錄，分析系統趨勢
- **自動數據保存**: 健康檢查結果自動存入 server_data.json
- **精準調度**: 每小時15分和45分自動執行健康檢查 :new:

#### :wrench: 自動化運維系統 :new:
- **每日維護任務**: 日誌清理、備份管理、數據優化、任務重新調度 :new:

#### :video_game: Discord Commands

##### 基本功能
- `/rate` - 查詢當前日幣匯率
- `/threshold` - 設定監控閾值 (管理員)
- `/channel` - 設定通知頻道
- `/status` - 查看機器人狀態
- `/help` - 顯示幫助訊息

##### 進階功能
- `/chart` - 生成匯率趨勢圖表
- `/backup` - 手動創建數據備份 (管理員)
- `/list_backups` - 列出所有備份檔案

##### 系統管理功能 :new:
- `/system` - 系統狀態檢查 (快速/詳細模式)
- `/health` - 健康監控檢查 (快速/全面模式)
- `/maintenance` - 系統維護操作 (摘要/每日/緊急)

## ⚡ 最新優化

### � 精準時間調度系統 🆕
- **匯率檢查**: 每小時的整點和30分精確執行 (如: 10:00, 10:30, 11:00...)
- **健康檢查**: 每小時的15分和45分精確執行 (如: 10:15, 10:45, 11:15...)
- **每日備份**: 每天凌晨0:00自動執行

- **時間同步**: 避免傳統polling的時間漂移問題，確保長期穩定性
