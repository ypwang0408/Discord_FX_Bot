# 🎮 Discord 指令完整指南

## 📊 基本功能指令

### `/rate` - 查詢當前匯率
**功能**: 即時查詢玉山銀行日幣匯率
```
使用方式: /rate
權限需求: 無
回應時間: 1-3秒
```

### `/threshold` - 設定監控閾值
**功能**: 設定匯率通知的觸發閾值
```
使用方式: /threshold 0.21
參數: 閾值 (0.1-1.0)
權限需求: 管理員
預設值: 0.2
```

### `/channel` - 設定通知頻道
**功能**: 將當前頻道設為匯率通知頻道
```
使用方式: /channel
權限需求: 無
注意: 每個伺服器只能設定一個通知頻道
```

### `/status` - 查看運行狀態
**功能**: 顯示機器人當前運行狀態
```
使用方式: /status
權限需求: 無
顯示內容: 運行時間、最後檢查時間、通知設定
```

### `/help` - 顯示幫助
**功能**: 顯示所有可用指令的說明
```
使用方式: /help
權限需求: 無
語言: 中英文雙語
```

### `/rules` - 通知規則說明
**功能**: 詳細說明智能通知的觸發條件
```
使用方式: /rules
權限需求: 無
內容: 三種通知條件的詳細說明
```

## 📈 進階功能指令

### `/chart` - 生成匯率圖表
**功能**: 生成指定天數的匯率趨勢圖表
```
使用方式: /chart days:7
參數: days (1-30天)
輸出格式: 高解析度 PNG 圖片
特色: 包含閾值線、趨勢分析、統計資訊
```

**圖表功能**:
- 📊 專業視覺化設計
- 📈 自動趨勢分析
- 🎯 閾值線標示
- 📅 時間軸標籤
- 💹 統計摘要資訊

### `/backup` - 手動備份
**功能**: 立即創建完整數據備份
```
使用方式: /backup
權限需求: 管理員
備份內容: 伺服器設定、匯率歷史、健康檢查記錄
檔案格式: JSON (含時間戳)
```

### `/list_backups` - 列出備份
**功能**: 顯示所有可用的備份檔案
```
使用方式: /list_backups
權限需求: 管理員
顯示資訊: 檔案名稱、大小、創建時間、伺服器數量
排序: 按時間倒序
```

## 🔧 系統管理指令

### `/system` - 系統狀態檢查
**功能**: 全面的系統健康和狀態檢查
```
使用方式: 
  /system                    # 快速模式
  /system detailed:True      # 詳細模式

快速模式顯示:
- 整體系統狀態
- 運行時間
- 記憶體使用量
- 健康指示器

詳細模式顯示:
- 完整健康檢查報告
- 系統資源使用情況
- 維護狀態摘要
- 系統建議
```

### `/health` - 健康監控
**功能**: 專門的系統健康檢查和診斷
```
使用方式:
  /health                    # 快速檢查
  /health quick:False        # 全面檢查

檢查項目:
- 🌐 API 連通性和響應時間
- 💾 系統資源使用情況 (CPU、記憶體、磁碟)
- 📊 數據完整性驗證
- 📁 重要檔案存在性檢查
- 🔄 服務狀態檢查

輸出格式:
- 整體健康評級 (健康/警告/錯誤)
- 詳細檢查結果
- 警告和錯誤列表
- 改善建議
```

### `/maintenance` - 系統維護
**功能**: 執行各種系統維護操作
```
使用方式:
  /maintenance                      # 維護摘要
  /maintenance operation:summary    # 維護摘要 (同上)
  /maintenance operation:daily      # 每日維護
  /maintenance operation:emergency  # 緊急清理

維護類型:
- summary: 顯示最近24小時的維護活動
- daily: 執行完整的每日維護任務
- emergency: 執行緊急清理和優化

每日維護包含:
- 🗑️ 日誌檔案清理 (保留7天)
- 💾 備份檔案管理
- 📊 數據完整性檢查
- 🔧 性能優化
- 📈 系統健康記錄更新
```

### `/permissions` - 權限檢查
**功能**: 驗證機器人在當前伺服器的權限設定
```
使用方式: /permissions
權限需求: 無
檢查項目:
- 發送訊息權限
- 嵌入連結權限  
- 使用斜線命令權限
- @everyone 提及權限 (可選)
- 讀取訊息歷史權限
```

### `/sync` - 同步指令
**功能**: 手動重新註冊所有 Slash Commands
```
使用方式: /sync
權限需求: 管理員
用途: 修復指令顯示問題或更新指令
注意: 可能需要等待數分鐘才會生效
```

### `/mention` - 群組通知設定
**功能**: 啟用或停用 @everyone 群組通知
```
使用方式: /mention
權限需求: 無
功能: 切換當前伺服器的 @everyone 通知設定
狀態: 顯示目前設定並提供切換選項
```

## 🎯 指令使用技巧

### 🚀 快速上手流程
1. **初始設定**: `/channel` → `/threshold 0.21`
2. **驗證設定**: `/status` 確認配置
3. **測試功能**: `/rate` 查看當前匯率
4. **生成圖表**: `/chart days:7` 查看趨勢

### 💡 進階使用技巧
- **系統監控**: 定期使用 `/system` 檢查狀態
- **數據備份**: 重要變更前使用 `/backup`
- **故障排除**: 問題發生時依序使用 `/permissions` → `/health` → `/system detailed:True`
- **性能優化**: 定期使用 `/maintenance operation:daily`

### ⚠️ 常見注意事項
- 管理員指令需要 Discord 伺服器管理權限
- 圖表生成可能需要數秒時間
- 系統維護期間可能會有短暫延遲
- 備份檔案會自動清理，重要資料請及時保存

## 🔍 故障排除指令流程

### 問題: 通知未收到
```
1. /status        # 檢查基本設定
2. /permissions   # 驗證權限
3. /rate          # 測試基本功能
4. /rules         # 確認通知條件
```

### 問題: 系統異常
```
1. /health                    # 快速健康檢查
2. /health quick:False        # 全面健康檢查
3. /system detailed:True      # 詳細系統報告
4. /maintenance operation:daily  # 執行維護
```

### 問題: 資料遺失
```
1. /list_backups             # 查看可用備份
2. /backup                   # 創建當前狀態備份
3. 聯繫管理員進行資料恢復
```
